# روزینو (Rozino) — تبدیل به اپ اندروید

این پوشه شامل اپ وب فعلی (بدون هیچ تغییری در ظاهر، رنگ‌ها، Layout یا منطق برنامه) به‌علاوه‌ی
تمام فایل‌های لازم برای تبدیل آن به یک اپ واقعی اندروید با Capacitor است.

کارهایی که از قبل انجام شده:
- `www/index.html` → همان اپ فعلی، با چند اصلاح ضروری برای موبایل (بدون تغییر ظاهر):
  عنوان و نام برند به «روزینو» تغییر کرد، متا‌تگ‌های موبایل اضافه شد، و یک لایه‌ی
  اتصال به Capacitor داخل کد اضافه شده که:
  - `NotificationPort` وب را در صورت اجرا داخل اپ اندروید، خودکار با `CapacitorNotificationPort`
    (روی پلاگین `@capacitor/local-notifications`) جایگزین می‌کند — دقیقاً همان معماری‌ای که
    کامنت‌های خود کد از قبل برایش پیش‌بینی شده بود.
  - دکمه Back فیزیکی اندروید را مدیریت می‌کند (اول Date Picker، بعد مودال‌ها، بعد رفتار پیش‌فرض).
  - رنگ نوار وضعیت (Status Bar) را با تم روشن/تاریک برنامه هماهنگ می‌کند.
  - Splash Screen را بلافاصله بعد از آماده شدن رابط کاربری می‌بندد.
- `resources/icon.png`, `resources/splash.png`, `resources/splash-dark.png` → لوگو و اسپلش
  اختصاصی «روزینو» (هماهنگ با رنگ‌بندی طلایی/ایوری فعلی برنامه)، آماده برای تولید خودکار
  آیکون‌های اندروید در همه‌ی density ها.
- `resources/notification-icon.png` + `android-assets/res/drawable-*/ic_stat_notify.png` →
  آیکون تک‌رنگ (سفید) مخصوص نوار اعلان‌ها، در تمام سایزهای لازم، آماده‌ی کپی مستقیم.
- `package.json` و `capacitor.config.json` → تنظیمات کامل Capacitor.

## چرا اینجا Build نهایی انجام نشده؟

محیطی که این پروژه در آن آماده شده، به اینترنت و Android SDK/Gradle دسترسی ندارد
(این دو، برای دانلود پلاگین‌های npm و کامپایل واقعی APK لازم‌اند). به همین دلیل مراحل زیر
باید یک‌بار، روی کامپیوتر خودتان، اجرا شوند. همه‌چیز از قبل آماده است؛ این مراحل فقط
«سرهم‌بندی نهایی» هستند و معمولاً کمتر از ۱۰ دقیقه طول می‌کشند.

## پیش‌نیاز روی کامپیوتر شما

1. **Node.js** (نسخه ۱۸ به بالا) — از nodejs.org
2. **Android Studio** (شامل Android SDK و JDK) — از developer.android.com/studio

## مراحل دقیق

در ترمینال، داخل همین پوشه‌ی پروژه (جایی که `package.json` قرار دارد):

```bash
# ۱) نصب وابستگی‌های Capacitor
npm install

# ۲) ساخت پروژه واقعی اندروید (پوشه android/ ساخته می‌شود)
npx cap add android

# ۳) کپی آیکون نوار اعلان (notification icon) داخل پروژه‌ی اندروید
#    محتوای پوشه‌ی android-assets/res را داخل android/app/src/main/res کپی/ادغام کنید:
#    (در macOS/Linux)
cp -r android-assets/res/* android/app/src/main/res/
#    (در Windows PowerShell)
#    Copy-Item -Recurse -Force android-assets\res\* android\app\src\main\res\

# ۴) تولید خودکار آیکون لانچر و اسپلش‌اسکرین برای همه‌ی سایزها/تراکم صفحه
npx @capacitor/assets generate --android

# ۵) همگام‌سازی وب‌اپ + تنظیمات با پروژه‌ی اندروید
npx cap sync android

# ۶) باز کردن پروژه در Android Studio
npx cap open android
```

بعد از باز شدن Android Studio:

1. صبر کنید Gradle Sync تمام شود (بار اول ممکن است چند دقیقه طول بکشد، چون
   Gradle و کتابخانه‌های اندروید را دانلود می‌کند — نیاز به اینترنت دارد).
2. برای نصب مستقیم روی گوشی: گوشی را با کابل وصل کنید (حالت USB Debugging فعال)،
   و دکمه‌ی سبز **Run ▶** را بزنید.
3. برای گرفتن فایل نصبی APK: از منوی
   **Build → Build Bundle(s) / APK(s) → Build APK(s)**
   استفاده کنید. فایل خروجی در
   `android/app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## نکات مهم

- **نام و شناسه‌ی اپ:** نام اپ («روزینو») و شناسه‌ی پکیج (`com.rozino.app`) از قبل در
  `capacitor.config.json` تنظیم شده‌اند. اگر می‌خواهید شناسه‌ی پکیج را عوض کنید،
  این کار را **قبل از** مرحله‌ی ۲ (`npx cap add android`) انجام دهید.
- **دسترسی نوتیفیکیشن:** پلاگین `@capacitor/local-notifications` خودش مجوز لازم
  (از جمله `POST_NOTIFICATIONS` برای اندروید ۱۳ به بالا) را به Manifest اضافه می‌کند؛
  کار اضافه‌ای لازم نیست. برنامه هنگام اجرا این مجوز را از کاربر می‌پرسد.
- **RTL و فارسی:** چون کل رابط کاربری داخل یک WebView نمایش داده می‌شود، جهت راست‌به‌چپ
  و فونت فارسی دقیقاً همان چیزی است که در نسخه‌ی وب می‌بینید — چیزی تغییر نکرده.
- **دکمه Back:** نیازی به تغییر کد نیتیو نیست؛ Capacitor به‌صورت پیش‌فرض فشردن دکمه Back
  را به رویداد `backButton` در جاوااسکریپت می‌فرستد و کد داخل `www/index.html` آن را
  مدیریت می‌کند (بستن Date Picker/مودال‌ها، یا رفتار پیش‌فرض اگر چیزی باز نبود).
- **فونت آفلاین (اختیاری):** فونت Vazirmatn فعلاً از CDN (jsdelivr) بارگذاری می‌شود.
  روی گوشی با اینترنت مشکلی ندارد، ولی اگر می‌خواهید برنامه کاملاً آفلاین هم فونت درست
  را نشان دهد، فایل‌های فونت را داخل `www/fonts/` کپی کنید و لینک CDN را در
  `www/index.html` با یک `@font-face` محلی جایگزین کنید. (این تغییر اختیاری است و در
  این نسخه انجام نشده چون نیاز به دانلود فونت از اینترنت داشت.)
